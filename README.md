# Smart Learning Management System (SLMS)

Static frontend demo for a college LMS.

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Important
The `assignment-files` folder contains the three Word documents used by `assignments.html`.

## Modules
Dashboard, Courses, Attendance, Marks & Performance, Assignments, Learning Resources, Smart Recommendations, Announcements, Profile, Login.

This is the frontend/demo version. A future backend can replace the sample data with FastAPI + PostgreSQL APIs.
